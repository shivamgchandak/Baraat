Baraat - Local Setup
====================

Steps to run the whole project on your machine.


1. INSTALL DEPENDENCIES
-----------------------
pnpm install


2. CREATE THE ENV FILES
-----------------------
cp .env.example .env
cp apps/guest/.env.example apps/guest/.env

Then open .env and fill in DATABASE_URL / DIRECT_URL (Supabase or local
Postgres) and the two JWT secrets. In apps/guest/.env, set EXPO_PUBLIC_API_URL
to your computer's LAN IP, e.g. http://192.168.1.5:4000


3. SET UP THE DATABASE
----------------------
pnpm --filter @baraat/db generate        # generate the Prisma client
pnpm --filter @baraat/db migrate:deploy   # create the tables
pnpm --filter @baraat/db rls:apply        # apply row-level security
pnpm db:seed                              # create the admin login only

Seeded admin: admin@baraat.events / password123


4. START EVERYTHING
-------------------
Run each in its own terminal:

pnpm api          # API             -> http://localhost:4000
pnpm dispatch     # matching engine (must be running to auto-assign rides)
pnpm portal       # admin/driver web -> http://localhost:3000

Guest app (React Native / Expo):

cd apps/guest
pnpm start        # scan the QR with Expo Go on a phone (same Wi-Fi)
